# Ledge Diary — Releases

이 저장소는 Ledge Diary 설치 파일 배포용입니다. 소스 코드는 포함하지 않습니다.

- 최신 버전 다운로드: https://github.com/bridgelab2025/ledge-calendar-releases/releases/latest
  - 설치형 `ledge-v<버전>-setup.exe`, 포터블 `ledge-v<버전>-portable.exe`
- 체크섬: 각 릴리즈의 `SHA256SUMS.txt`

앱은 웹사이트의 `releases/latest.json`을 읽어 새 버전을 확인하고, 이 저장소에서 파일을 내려받아 SHA-256을 검증한 뒤 교체합니다.
